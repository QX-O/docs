## What this repo is

This is a Mintlify documentation site. You write pages in MDX, list them in `docs.json`, and preview or publish them as a clean documentation-style website.

For your use case, think of it as a personal knowledge base with three layers:

1. **Indexes** that help you find notes quickly.
2. **Individual notes** for ideas, verses, themes, and reflections.
3. **Templates** that keep every note consistent.

## Add a new idea note

1. Copy `templates/idea-note.mdx`.
2. Paste it into the `ideas/` folder.
3. Rename it with a short, lowercase slug, such as `ideas/prayer-app.mdx`.
4. Update the title, description, status, tags, and content.
5. Add the page path to `docs.json` under the `Ideas` group.
6. Add a link from `ideas/index.mdx`.

Example page path for `docs.json`:

```json
"ideas/prayer-app"
```

## Add a new Bible verse note

1. Copy `templates/verse-note.mdx`.
2. Paste it into the `scripture/` folder.
3. Rename it by reference, such as `scripture/john-3-16.mdx`.
4. Add the passage reference, translation, context, themes, and reflection.
5. Add the page path to `docs.json` under the `Scripture` group.
6. Add a link from `scripture/index.mdx`.

Example page path for `docs.json`:

```json
"scripture/john-3-16"
```

## Decide what should be public

Before publishing, separate private notes from public notes.

<Warning>
  Do not publish private journal entries, confidential ideas, personal prayer requests, or sensitive details unless you truly intend them to be public.
</Warning>

A good workflow is:

- capture rough private notes somewhere else,
- move polished notes into this repo,
- publish only what you are comfortable sharing.

## Preview locally

Install Mintlify:

```bash
npm i -g mintlify
```

Run the preview from the repository root:

```bash
mintlify dev
```

## Maintain the index

When you add a note, update two places:

- `docs.json` so it appears in the sidebar,
- the relevant index page so you can browse notes by topic.

This small habit keeps the repo useful as it grows.
